Hotel Feedback Form
A simple HTML5 feedback form for hotel guests to share their experience.
This project demonstrates semantic HTML, form validation, and user‑friendly design.
Features
- Personal Information
- Name (required)
- Email (required)
- Age (optional)
- Hotel Stay Information
- Radio buttons to indicate if it was the guest’s first stay
- Reasons for Choosing the Hotel
- Multiple checkboxes (Ads, Recommendation, Location, Reputation, Price)
- Ratings
- Dropdown menus to rate Service and Food
- Additional Comments
- Textarea for open‑ended feedback
- Submit Button
- Sends form data via POST to:
https://hotel-feedback.example.org
Technologies Used
- HTML5
- Semantic elements (<header>, <main>, <fieldset>, <legend>)
- Built‑in form validation (required, type="email", min/max for age)
